# Құпия Санта

Сайт для игры «Тайный Санта» полностью на казахском языке. Хост создаёт игру и отправляет ссылку друзьям. Участники входят через Google и заполняют анкету: имя, пол, что хотят получить, чего не дарить, по желанию фото. Когда все записались, хост проводит жеребьёвку.

## Как работает жеребьёвка

- Мужчина всегда дарит подарок женщине.
- Женщины дарят мужчинам. Если мужчин меньше, оставшиеся женщины дарят женщинам.
- Никто не дарит сам себе, и каждый получает ровно один подарок.
- Если можно, жеребьёвка не создаёт пары, где двое дарят друг другу.
- Если мужчин больше, чем женщин, жеребьёвка не запустится: сайт напишет, сколько ещё женщин нужно.
- Результат каждого участника зашифрован его личным ключом. Даже хост не видит, кто кому дарит.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `index.html` | Страница: дизайн, тексты, формы |
| `app.js` | Логика: вход, игра, анкеты, жеребьёвка, шифрование |
| `firebase-config.js` | Данные вашего проекта Firebase, их нужно вставить один раз |
| `firestore.rules` | Правила безопасности базы, их нужно вставить в Firebase один раз |

## Настройка Firebase (один раз, около 5 минут)

1. Откройте https://console.firebase.google.com и нажмите **Create a project**. Назовите, например, `qupiya-santa`. Google Analytics можно выключить.
2. На главной странице проекта нажмите значок **</>** (Web), введите любое имя приложения и нажмите **Register app**. Firebase покажет блок `const firebaseConfig = { ... }`. Скопируйте значения из него в файл `firebase-config.js` вместо `PASTE_...`.
3. В меню слева: **Build → Authentication → Get started**. На вкладке **Sign-in method** включите **Google** и сохраните.
4. В меню слева: **Build → Firestore Database → Create database**. Выберите регион (например, `europe-west`) и режим **production**.
5. В Firestore откройте вкладку **Rules**, замените всё содержимое текстом из файла `firestore.rules` и нажмите **Publish**.
6. **Authentication → Settings → Authorized domains → Add domain**: добавьте адрес сайта на GitHub Pages, например `ваш-логин.github.io`.

После этого отправьте изменения `firebase-config.js` на GitHub (или попросите Claude). Через минуту сайт заработает.

## Хостинг на GitHub Pages

Сайт статический, сборка не нужна. В репозитории: **Settings → Pages → Source: Deploy from a branch → main / (root)**. Адрес сайта: `https://ваш-логин.github.io/qupiya-santa/`.

## Как играть

1. Откройте сайт, войдите через Google и нажмите **Ойын құру** (создать игру).
2. Заполните название, сумму подарка, дату жеребьёвки и дату вручения. На вкладке **Безендіру** можно загрузить своё фото в образе Санты.
3. Нажмите **Шақыру** и отправьте ссылку участникам.
4. Когда все записались, нажмите **Жеребе тарту** (провести жеребьёвку).
5. Каждый участник открывает свой конверт и видит, кому дарит подарок.
